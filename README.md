# 合租生活管家雏形

这是一个面向附加题的轻量级产品原型，聚焦于以下 4 个核心场景：

- 费用AA分摊
- 清洁值日排班
- 公共物品登记与提醒
- 室友公约管理

当前原型支持完整的本地交互：

- 自定义费用名称、金额、付款人、参与人数和分摊方式，并自动计算人均待付
- 自定义清洁任务、轮值成员、开始日期、执行时间和轮值周期
- 自定义公共物品名称、数量、提醒阈值和单位，并实时增减库存
- 自定义公约内容和级别
- 对费用、排班、物品和公约执行删除操作，费用还可标记结清
- 可在王强、李四和张三之间切换当前身份；记录会显示创建人，且只能由创建人删除
- 所有统计随数据变化实时更新，数据保存在当前浏览器中

## 在线访问方式

### 方案 A：Vercel（最省时）

1. 将当前项目上传到 GitHub。
2. 进入 https://vercel.com，导入该仓库。
3. 选择默认设置后部署。
4. Vercel 会生成一个公开访问链接，后续可以继续在同一域名下更新内容。

### 方案 B：Netlify

1. 将当前项目上传到 GitHub。
2. 在 Netlify 中选择该仓库并部署。
3. 部署完成后即可获取公开链接。

## 本地预览

在项目根目录运行：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

## 设计思路

这个原型的重点不是技术复杂度，而是展示：

1. 你能把真实合租痛点转化成产品能力。
2. 你的交互设计和信息架构是清晰的。
3. 你具备把“普通页面”做成一个可用产品雏形的能力。

## 建议的附加题表现方式

在最终提交链接时，建议在产品页中展示以下内容：

- 首页总览：本月支出、待收款、清洁提醒、低库存物品
- AA分摊模块：费用项目 + 分摊方式 + 未支付金额
- 清洁值日：本周值日安排、轮值变化
- 物品登记：什么物品、库存如何、是否提醒补货
- 公约管理：强调尊重、共享责任、记录规则

## 备注

如果你希望后续继续迭代成“带后端的真实产品”，可以在 48 小时内扩展为：
